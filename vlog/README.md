# Educational Vlog Scripts

**Proposed series:** From Classroom to Research: Epidemiology & Biostatistics  
**Intended audience:** undergraduates beginning clinical and public health research.

Students write teach-back scripts after learning lessons; material is reviewed for scientific accuracy and citations before dissemination. Drafts, reviewed scripts and published scripts must be clearly differentiated.

## Status vocabulary
- **Draft** — author's working text
- **Under scientific review** — terminology, logic, methodology and evidence are being checked
- **Reviewed** — corrections resolved; ready for creator's final approval
- **Published** — external publication recorded by author

Each script should distinguish evidence-based facts, assumptions and illustrative examples. Cite external figures/sources as appropriate. Never include confidential research data or identifying patient records. No script has been drafted or approved yet.
