# Foundations of Epidemiology & Biostatistics
### From Classroom to Research · 流行病学与生物统计学基础

A structured, bilingual guide to epidemiology and biostatistics, bridging foundational concepts with practical **clinical and public health research**.

> **Status:** 🚧 Active course development. Lessons are published progressively and are clearly labeled until reviewed and completed.

## Why this project?
Many undergraduate students can recognize the terms *cohort study*, *confidence interval*, or *confounding* yet struggle to connect them into a reliable research decision-making framework. This open educational repository is designed to build that connection systematically.

- **Audience:** undergraduates beginning clinical, epidemiologic, and public health research
- **Language:** English-first for scientific terminology and conceptual explanations, supported by Chinese clarifications
- **Method:** conceptual framework → precise definitions → reasoning and assumptions → varied applied examples → critical interpretation
- **Pacing:** one manageable, internally complete block at a time; questions before automatic advancement
- **Scope:** general, transferable principles; examples from diverse medical/public-health questions, with individual projects serving only as optional illustrations
- **Output:** reviewed learning notes and optional student-written educational Vlog scripts

## Teaching & Synchronization

1. At the beginning of a new session, read the protocol, current state, syllabus and active lesson.
2. Teach **one coherent block** with its definitions, relationships, relevant assumptions and scope.
3. Pause for the learner's questions. A taught block is not automatically mastered.
4. **After each substantive block**, update and commit the current state and working lesson.
5. **After a fully reviewed lesson**, audit its completeness and update the lesson note, progress, README and changelog.
6. For the Vlog track, the learner writes a script and it undergoes a separate scientific review before being called approved.

**Note:** GitHub updates happen through an authorized connected tool during active conversations. This repository does not imply always-on background synchronization or automatic scientific verification.

## Important Boundaries

**Public repository:** do not commit confidential research materials, unpublished manuscripts, identifiable patient data, third-party teaching slides, or materials without permission. Examples should be appropriately sourced, anonymized, or synthetic.

**Educational purpose:** methodological teaching; not individual medical advice. Sources and assumptions should be identified when appropriate. The repository has no explicit open-source/content license yet.
